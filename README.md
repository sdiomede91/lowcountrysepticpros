# lowcountrysepticpros.com

Static site for Lowcountry Septic Pros, hosted on Vercel. Every push to `main` deploys automatically.

## How it's built
All pages are generated by one script and the output `.html` files are committed. Vercel serves them as-is, with no build step on Vercel.

    python3 tools/build.py

| What to change | Where |
|---|---|
| Phone, email, licence wording | `BUSINESS` at the top of `tools/build.py` |
| Header, footer, page layout, schema | `tools/build.py` |
| Home, About, Contact, Privacy, Terms copy | `tools/pages/*.html` |
| Service pages (copy, FAQs, price ranges) | `tools/content_services.py` |
| Location pages, other towns served | `tools/content_locations.py` |
| Quote form fields | `tools/pages/_quote_form.html` |
| Styling | `styles.css` |

Never edit the root `.html` files by hand; they're overwritten on every build.

## Quote form
The form posts to `api/quote.js`, a Vercel serverless function that forwards the request to FormSubmit by
email. The destination inbox never appears in the page source. To change it, set `QUOTE_EMAIL` in
Vercel → Project → Settings → Environment Variables (the default is info@lowcountrysepticpros.com).
The first submission triggers a one-time FormSubmit activation email to that inbox; click it, then
send a second test.
